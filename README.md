# FlowForge

## Overview

FlowForge is an enterprise workflow automation platform built using a microservices architecture.

It allows organisations to create dynamic workflows, configurable forms, approval processes and document management.

---

## Tech Stack

### Frontend

- Angular
- Angular Material
- TypeScript
- SCSS

### Backend

- Java 21
- Spring Boot
- Spring Cloud

### Infrastructure

- PostgreSQL
- Redis
- Kafka
- MinIO
- Docker
